# Pokémon Archive

My Pokémon journey began on December 26, 2009. Since then, the Pokémon games have accompanied me through many generations and have become a collection that I have continued to build for many years.

As a collector, I created this repository to preserve and document that journey. It serves as a personal archive of my Pokémon collection across the different generations and games, including Pokémon I have collected, special and event Pokémon, my original playthrough teams, and backups of my save data.

## Repository Structure

The archive is organized first by generation and then by game.

Each game can contain the following folders:

* **Pokemon** – Pokémon originating from or collected for that game.
* **Special Pokemon** – Event Pokémon, special gifts, NPC trades, unusual encounters, legacy Pokémon, and other notable specimens.
* **Team** – The Pokémon that were part of my personal playthrough team.
* **Save** – Backups of my personal save data.
* **ROM** – Local backups of game media. This folder and its contents are explicitly excluded from Git and are never part of this repository.

## Preservation

Where possible, Pokémon are archived in their native generation format before being transferred to later generations or Pokémon HOME.

The goal is not only to maintain a collection, but also to preserve the history and provenance of the Pokémon within it: the game they came from, special encounters and events, and the teams that accompanied me through each playthrough.

Some historical Pokémon or events that are no longer normally obtainable may be reconstructed using preservation tools such as PKHeX or PKSM. In those cases, the Pokémon should remain consistent with combinations that were legitimately obtainable in the original games.

## File Naming

Pokémon files are generally named using their National Pokédex number followed by the Pokémon's name and, where relevant, its form or other distinguishing information.

Examples:

`0025 - Pikachu.pk4`

`0487 - Giratina - Origin Form.pk4`

`0025 - Pikachu - Female.pk4`

## Notes

This repository is intended as a personal preservation archive.

Game ROMs and other game images are not tracked or stored in this repository.
